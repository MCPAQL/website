About MCPAQL

MCPAQL (Model Context Protocol Query Language) is an open specification designed to provide an efficient GraphQL-like syntax for making tool calls to MCP servers and other APIs used by:

  • Operating Systems
  • Websites
  • Applications
  • Cloud Services

This open-source specification is designed to work in conjunction with DollhouseMCP, utilizing memory and template elements, but may also be implemented separately for standalone use cases.

Specification

The MCPAQL specification defines a query language that enables efficient communication between AI models and MCP servers. Key features include:

GraphQL-like Syntax

Familiar, expressive query syntax for developers

Tool Calls

Streamlined API for invoking server-side tools

Memory Integration

Works with DollhouseMCP memory elements

Template Support

Reusable templates for common operations

Implementations

MCPAQL is designed to be implemented across various platforms and languages. Reference implementations and community contributions are welcome.
